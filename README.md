# ElJumush (ЭлЖумуш) — PWA проверки прозрачности вакансий в Кыргызстане

**ElJumush** — мобильно-ориентированное прогрессивное веб-приложение (PWA) для первичного анализа текстов вакансий в Кыргызстане на предмет прозрачности условий: оклада, периодичности выплат, графика работы, скрытых взносов и сомнительных требований.

Приложение работает **полностью в браузере**, без серверной части, без сторонних API, без ИИ и сохраняет данные исключительно в локальном хранилище `localStorage` вашего устройства.

## 🚀 Быстрый старт

### Требования
- Node.js 18.x или выше (протестировано на Node.js 20+ / 26)
- npm 9+ или pnpm / yarn

### Установка зависимостей
```bash
npm install
```

### Генерация иконок PWA (если требуется обновить)
```bash
npm run icons
```

### Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 📱 Тестирование PWA (Progressive Web App)

### 1. Проверка Манифеста и Service Worker в Chrome DevTools
1. Откройте приложение в браузере Chrome: `http://localhost:3000`.
2. Нажмите `F12` (или `Ctrl + Shift + I` / `Cmd + Option + I`), чтобы открыть Chrome DevTools.
3. Перейдите во вкладку **Application** (Приложение):
   - **Manifest**: убедитесь, что имя «ElJumush — прозрачные условия вакансий», иконки (192x192, 512x512, maskable) и параметры отображения (`standalone`) подгрузились без ошибок.
   - **Service Workers**: проверьте статус воркера (`/sw.js` — активирован и работает `activated and is running`).
   - **Storage** / **Cache Storage**: убедитесь, что кэш `eljumush-v1` создан и содержит закэшированные ресурсы (`/`, `/form`, `/manifest.json`, иконки).

### 2. Тестирование офлайн-режима (Airplane Mode)
1. Откройте главную страницу `http://localhost:3000` и страницу анализа `/form`.
2. В Chrome DevTools перейдите во вкладку **Network** (Сеть) или **Application** → **Service Workers**.
3. Установите чекбокс **Offline** (или отключите сеть / включите режим «В самолёте»).
4. Обновите страницу (`F5` или `Ctrl + R`).
5. Убедитесь, что приложение открывается офлайн, отображается баннер «Вы офлайн», а анализ текста продолжает корректно работать локально.

### 3. Lighthouse PWA Audit
1. В Chrome DevTools откройте вкладку **Lighthouse**.
2. Выберите категорию **Progressive Web App** и устройство **Mobile**.
3. Нажмите кнопку **Analyze page load**.
4. Проверьте критерии PWA (Installable, Service Worker, Manifest, Viewport, Theme Color).

## ⚠️ Что НЕ реализовано (по дизайну архитектуры)

ElJumush сознательно спроектирован как полностью клиентский инструмент, уважающий приватность пользователя:
- ❌ **Учетные записи и регистрация пользователей**: профили не требуются.
- ❌ **Внешняя база данных**: история и обращения хранятся исключительно в `localStorage` браузера пользователя.
- ❌ **Автоматическое скачивание содержимого по URL**: приложение не делает внешних HTTP-запросов к сайтам вакансий (ссылка сохраняется только как текстовая заметка соискателя).
- ❌ **Нейросети и сторонние AI API**: анализ выполняется прозрачными детерминированными правилами и регулярными выражениями без отправки данных на серверы.
- ❌ **Проверка по государственным реестрам и верификация бизнеса**: приложение анализирует только текст объявления и не подтверждает регистрацию юридического лица или добросовестность работодателя.
